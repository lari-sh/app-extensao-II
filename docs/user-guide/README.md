# Manual de instalação Android

[Guia de instalação e avaliação em Word](guia_instalacao_android.docx), preparado
para acompanhar o APK entregue ao professor. Inclui instalação por arquivo,
acesso de visitante e funcionário, roteiro de avaliação e solução de dificuldades.
Não contém senhas ou chaves de backend.

A cópia de envio fica em `entrega-professor/guia_instalacao_android.docx`, junto
do APK. Essa pasta local é ignorada pelo Git. Informar a senha de funcionário
separadamente; o acesso de administrador não acompanha a entrega.

[Cópia editável no Google Docs](https://docs.google.com/document/d/1S5ejVto6CXuWYlH_T_Sv8JUKqdHgXdPGjZVeGFzdRyg)
criada na pasta ChatGPT do Drive conectado. Acesso depende das permissões do Drive;
nenhuma permissão pública ou compartilhamento com o professor foi configurado.

Revisão de 03/11/2026: duas páginas Letter, PDF exportado pelo Google Docs e ambas
as páginas inspecionadas em PNG. Leitura de retorno e comparação do texto do DOCX
exportado confirmaram preservação do conteúdo. Fonte de instruções Android citada
no próprio manual. O arquivo pode ser aberto no Word ou importado no Google Docs.
